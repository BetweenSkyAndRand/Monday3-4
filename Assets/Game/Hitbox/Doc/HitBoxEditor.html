DOD.HitBox.Editor — Unity Editor 拡張

グリッドベースのヒットボックス配置ツール。セルをクリックしてコライダー座標を定義し、JSON として保存します。

メニュー: DOD > Tools > HitBox Editor から開きます（最小サイズ 540×560）。

ウィンドウ構成

ウィンドウは 3 パネル で構成されています。上段左右＋下段全幅のレイアウトです。

① サイドパネル HitBoxSidePanelView
幅 160px。配置済みコライダー一覧。
ボタン — 選択 / 解除（選択中はシアン背景）
x ボタン — 個別削除
テキストフィールド — 選択時に展開、名前変更
Count: — 現在の配置数
Clear All — 全削除
② グリッドパネル HitBoxGridView
9×9 グリッド（セル 36px）。左クリックでトグル配置/削除。
中央列 (X=4) — Y 軸基準。黄色ボーダーでハイライト
最下行 (Y=0) — X 座標ラベルを表示
中央列セル — Y 座標ラベルを表示
P (4,−1) — グリッド下にプレイヤーインジケーター
③ ファイルパネル HitBoxFilePanelView
Collider Size — ランタイム側コライダーサイズ・オフセット合わせ用 float（設定アセットに永続化）
Save Path — JSON 出力先。直接入力または ... ダイアログ選択（設定アセットに永続化）
Save JSON — 現在データを JSON 書き出し ／ Load JSON — ファイル選択して読み込み（現データ上書き）

グリッドの座標系

定数値意味
GridHalfX4中央列インデックス（X=4 が Y 軸基準列）
GridMinY0最下行の Y 値（X 軸ラベルを表示）
GridMaxY8最上行の Y 値
GridCountX9列数（GridHalfX×2+1）
GridCountY9行数（GridMaxY−GridMinY+1）

座標変換（グリッド表示座標 → JSON 保存値）

グリッドクリック時の (cx, cy) は ToRelX / ToRelY で変換されて ColliderData.x / y に保存されます。

// X: グリッド中央列(4)を原点0にシフト
private float ToRelX(int cx) => cx - GridHalfX;  // cx - 4
// Y: グリッド値をそのまま保存
private float ToRelY(int cy) => cy;
クリックセル (cx, cy)保存 x保存 y備考
(4, 0)00プレイヤー直上・中央
(3, 0)−10プレイヤー直上・左1
(5, 0)10プレイヤー直上・右1
(4, 1)01中央・2段上
(0, 8)−48左端・最上行
(8, 8)48右端・最上行
保存値の範囲: x: −4 〜 +4（プレイヤー X 相対） ／ y: 0 〜 8（グリッド Y そのまま）
Collider Size は座標変換に影響しません。変更時に HitBoxData.colliserSize に書き込まれ、ランタイム側で使用します。

基本操作

コライダーの配置・削除

  • グリッドセルを 左クリック → コライダーが追加され緑になる。名前は Collider_00 形式で自動付与。

  • 配置済みのセルを再クリック → 削除（トグル）。

コライダーの選択・名前変更

  • サイドパネルのコライダーボタンをクリック → 選択（シアン強調・グリッド連動）。再クリックで解除。

  • 選択中に展開されるテキストフィールドで名前を編集。

削除

  • コライダー行右端の x ボタン → 個別削除。

  • サイドパネル下部の Clear All → 全削除（selectedIndex もリセット）。

ファイルパネル

Collider Size

ランタイム側コライダーのサイズ・オフセット合わせ用の値（float、最小 0）。変更時に HitBoxEditorSettings アセットと HitBoxData.colliserSize に即時書き込まれます。

Save Path

JSON の出力先パス。テキスト直接入力か ... ボタンでダイアログ選択。変更は HitBoxEditorSettings アセットに即時保存。デフォルト: Assets/HitBox.json

Save JSON

現在の HitBoxData を Save Path に書き出します。ディレクトリが存在しない場合は自動生成。保存後 AssetDatabase.Refresh() を呼び出します。

Load JSON

ファイルダイアログで選択した JSON を読み込みます。現在のデータは上書きされます。読み込んだパスが Save Path に自動更新されます。

JSON フォーマット

JsonUtility.ToJson(data, prettyPrint:true) で書き出される形式です。

{
  "colliders": [
    { "name": "Collider_00", "x": 0.0, "y": 0.0 },
    { "name": "Collider_01", "x": -1.0, "y": 0.0 },
    { "name": "Collider_02", "x": 1.0, "y": 2.0 }
  ]
}

x: プレイヤー X 相対（−4〜+4）　y: グリッド Y そのまま（0〜8）　型: float

永続化アセット

保存先: Assets/Game/Hitbox/Data/HitBoxEditorSettings.asset
ウィンドウの OnEnable で毎回ロード。存在しなければ自動生成されます。
削除するとデフォルト値にリセットされます（SavePath: Assets/HitBox.json ／ ColliderSize: 1.0）。
